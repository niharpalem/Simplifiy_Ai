🔗 CLIP: Contrastive Language-Image Pre-training

OpenAI, 2021 | Simplify_AI Breakdown

📌 TL;DR

CLIP trains two neural networks (image encoder + text encoder) to understand that "a photo of a dog" and 🐕 should have similar representations. By learning from 400 million image-caption pairs from the internet, CLIP can classify images into any category described in natural language—without ever being explicitly trained on those categories.

1. The Problem with Traditional Image Classification

❌ Traditional Approach

  • Fixed categories: {cat, dog, car, ...}
  • Manual labeling required
  • Can't recognize new categories
  • Expensive & slow to scale

✅ CLIP's Approach

  • Any text description works
  • Learns from web captions
  • Zero-shot to new tasks
  • 400M pairs from internet
Key Insight: Internet image-caption pairs are essentially "free labels"—no manual annotation needed.

2.2 The Contrastive Learning Magic

Given a batch of N image-caption pairs, CLIP creates an N×N similarity matrix:

Image ↓ \ Text → "a cat" "a dog" "a car"
🐱 cat.jpg 0.9 ✓ 0.3 0.2
🐶 dog.jpg 0.2 0.8 ✓ 0.1
🚗 car.jpg 0.1 0.2 0.85 ✓

✓ Diagonal = correct pairs (maximize) | Off-diagonal = negatives (minimize)

2.3 The Loss Function (InfoNCE)

CLIP uses symmetric cross-entropy loss:

Limage→text = -1/N × Σ log( exp(sim(vi, ti)/τ) / Σj exp(sim(vi, tj)/τ) )
Ltext→image = -1/N × Σ log( exp(sim(ti, vi)/τ) / Σj exp(sim(ti, vj)/τ) )
Final Loss = (Limage→text + Ltext→image) / 2
τ (Temperature) controls sharpness of the probability distribution. CLIP makes τ a learnable parameter (optimized as log(τ) to keep it positive).

2.4 Worked Example

Computing loss for 🐱 ↔ "a cat":

Similarities: [0.9, 0.3, 0.2], τ = 0.1

P(correct) = e^(0.9/0.1) / (e^(0.9/0.1) + e^(0.3/0.1) + e^(0.2/0.1))
           = e^9 / (e^9 + e^3 + e^2)
           = 8103 / 8130
           ≈ 0.9966

Loss = -log(0.9966) = 0.0034  ✓ (small = good!)

3.1 Image Encoder Modifications

ResNet-D Improvements

Minor architectural tweaks: adjusted first convolution stride and downsampling paths → smoother gradients and stronger features.

Antialiased Pooling

Light blur before downsampling reduces aliasing artifacts, preserving edges and shapes when shrinking images.

🎯 Attention Pooling (Key Innovation)

Replaces global average pooling (which treats all pixels equally) with learned attention:

  • Input: final ResNet feature map (e.g., 7×7×C)
  • A global query vector attends to all spatial features
  • Important regions get higher weights, background less
Attn(Q, K, V) = softmax(QKT/√d) × V

Q = global query (summary), K & V = flattened image features from all positions

🔷 ViT Modifications

  • Adds LayerNorm after combining patch + positional embeddings (training stability)
  • Uses custom weight initialization tuned for contrastive training (better convergence)

3.2 Text Encoder

Standard Transformer with these specifics:

  • [SOS] and [EOS] special tokens wrap the text
  • Final [EOS] hidden vector → normalized → linearly projected to shared space
  • Uses causal (unidirectional) masking — each token only attends to previous tokens
  • Depth kept fixed (image encoder size matters more for performance)
Why [EOS]? The [EOS] token has "seen" the entire sentence through causal attention, making it a natural summary vector for the whole text.

4. Zero-Shot Classification

4.1 CLIP vs Visual N-Grams

CLIP redefines what "zero-shot" means:

Approach What it measures
Old zero-shot (Visual N-Grams) Can a model generalize to new object classes?
CLIP zero-shot Can a model generalize to new datasets/tasks using language?

📖 What is Visual N-Grams?

An older approach that predicts which 1-, 2-, 3-word phrases best describe an image using CNN features + a learned dictionary of text phrases. The top-scoring n-grams = most relevant descriptions.

CLIP authors specifically note their approach shouldn't be directly compared to Visual N-Grams—different goals.

4.3 Prompt Engineering Matters!

Raw labels often lack context. Better prompts improve accuracy:

Dataset Raw Label Better Prompt Why
ImageNet dog A photo of a dog. Natural language context
Oxford Pets boxer A photo of a boxer, a type of pet. Disambiguates from athlete
Food101 pizza A photo of pizza, a type of food. Matches CLIP's pretraining style
EuroSAT forest A satellite photo of a forest. Matches domain
GTSRB Stop 'STOP' sign. Helps OCR understanding

5. Training Design Decisions

From Scratch

No pre-trained weights for either encoder—both trained jointly.

Linear Projection

No activation function in final projection layer.

Single Caption

One caption per image (no sampling function needed).

Learnable τ

Temperature optimized during training as log(τ).

6. Few-Shot Learning Attempt

🧪 Experiment: Zero-Shot → Few-Shot Transfer

The authors tried using CLIP's zero-shot weights as priors for few-shot learning, adding an L2 regularization penalty:

Loss = Few-shot classification loss + λ ‖W - Wzero-shot‖²

What happened:

  • The regularization term dominated (λ too large)
  • Few-shot model just mimicked zero-shot behavior
  • No meaningful improvement from the few labeled examples
Takeaway: Simply regularizing toward zero-shot weights doesn't effectively transfer knowledge to few-shot settings. The model needs a different approach to leverage both zero-shot priors and labeled examples.

7. Evaluation & Analysis

7.1 Linear Probe

What is it? Freeze CLIP's image encoder, add a simple logistic regression classifier on top, train on labeled data. Tests how linearly separable the learned features are.

🤔 Why use Linear Probe?

Zero-shot CLIP might not align perfectly to specialized categories (like ethnicity, age, expression in FairFace dataset).

Instead of retraining CLIP from scratch:

  1. Freeze CLIP's image encoder (keep its rich features)
  2. Feed features into a lightweight classifier (logistic regression)
  3. Train only that small classifier on your labeled data

7.2 Data Overlap Analysis

To check if evaluation data leaked into training:

🔍 Duplicate Detector

  1. Flag each eval sample as Overlap or Clean
  2. Binomial significance test: Is Overlap accuracy significantly higher than Clean?
  3. Clopper-Pearson interval: Computes the uncertainty range around observed accuracy (confidence interval for binomial proportion)
Clopper-Pearson: An exact method for computing confidence intervals. If you observe 80/100 correct, the 95% CI might be [71%, 87%]. This tells you the true accuracy likely falls in that range.

7.3 Model Learning Terminology

❌ "Near Random"

Model hasn't learned anything meaningful for that dataset/task. Performance ≈ random guessing.

✅ "Well Above Random"

Model is actually recognizing patterns or successfully transferring knowledge.

8. Key Takeaways

✅ What CLIP Gets Right

  • Scale: 400M image-text pairs from the web
  • Flexibility: Zero-shot to any task describable in text
  • Robustness: Better distribution shift handling than supervised models
  • Efficiency: Sentence-level contrastive learning (not per-word)

⚠️ Limitations

  • Fine-grained classification (e.g., car models) still challenging
  • Abstract/systematic tasks (counting objects) difficult
  • Inherits biases from web data
