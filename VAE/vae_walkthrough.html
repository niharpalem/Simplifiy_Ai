Key Insight
Encoder outputs 32 channels (16 for mean + 16 for logvar), but the latent z is only 16 channels.

2
Encoder (CNN Compression)

The encoder compresses spatially (8× downsampling) and expands channels to z_dim × 2 = 32:

[1, 3, 1, 8, 8] → [1, 32, 1, 1, 1]
8×8 spatial → 1×1 spatial (8× compression)
3 channels → 32 channels (for mean + logvar)
# Encoder defined with z_dim * 2 output channels self.encoder = QwenImageEncoder3d( base_dim=96, out_channels=z_dim * 2, # 16 * 2 = 32 ... ) # Forward pass h = self.encoder(image) # [1, 32, 1, 1, 1] h = self.quant_conv(h) # [1, 32, 1, 1, 1] (1×1 conv)
Why 32 channels?
The encoder predicts a probability distribution for each latent dimension. It needs to output both μ (mean) and log(σ²) (log-variance) for all 16 latent channels.

4
Derive Standard Deviation

Convert log-variance to standard deviation:

σ = exp(log(σ²) / 2) = exp(logvar × 0.5)
Log-Variance (logvar)
[1, 16, 1, 1, 1]
Standard Deviation (σ)
[1, 16, 1, 1, 1]
# In DiagonalGaussianDistribution.__init__ self.std = torch.exp(0.5 * self.logvar) self.var = torch.exp(self.logvar)

Concrete Example (Channel 0)

logvar: -1.0
std: exp(-1.0 × 0.5) = exp(-0.5) = 0.606
var: exp(-1.0) = 0.368
Why use log-variance?
Variance must be positive. Using log-variance and then exp() guarantees positivity and is more numerically stable during training.
5
Sample Latent z (Reparameterization Trick)

Two options to get the latent z:

Option A: mode() - Deterministic
z = μ

Just return the mean. Used during inference for reproducibility.

Option B: sample() - Stochastic
z = μ + σ × ε    where ε ~ N(0,1)

Reparameterization trick. Used during training.

def mode(self): # Deterministic - just return mean return self.mean def sample(self, generator=None): # Reparameterization trick epsilon = randn_tensor(self.mean.shape, ...) # ε ~ N(0,1) z = self.mean + self.std * epsilon return z

Concrete Example (Channel 0)

mean (μ): 0.5
std (σ): 0.606
epsilon (ε): 0.3 (random from N(0,1))
mode(): z = 0.5
sample(): z = 0.5 + 0.606 × 0.3 = 0.682
Latent z: [1, 16, 1, 1, 1]
16 latent dimensions, compressed to a single spatial point
6
Decode Back to Image

The decoder takes the 16-channel latent and reconstructs the image:

[1, 16, 1, 1, 1] → [1, 3, 1, 8, 8]
1×1 spatial → 8×8 spatial (8× upsampling)
16 channels → 3 channels (RGB)
# Decode process x = self.post_quant_conv(z) # [1, 16, 1, 1, 1] - 1×1 conv out = self.decoder(x) # [1, 3, 1, 8, 8] - upsample out = torch.clamp(out, -1.0, 1.0) # clamp to valid range

Key Takeaways
  • Encoder outputs 2× latent channels (32) to represent both mean and variance
  • torch.chunk(2, dim=1) splits channels in half → mean (0-15) and logvar (16-31)
  • std = exp(logvar × 0.5) converts log-variance to standard deviation
  • Latent z is sampled using reparameterization trick: z = μ + σ × ε
  • Decoder only needs 16 channels (the sampled latent), not 32
